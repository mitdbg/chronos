- Diagnosis: Auth rotation plus append-mode `x-trace-baggage` grew headers from ~6 KB to ~78 KB, exceeding API Gateway/nginx buffers. Proxy buffering delayed flushes; the 30-second ALB idle timeout reset streams. No CPU/GPU saturation was observed.

- Mitigation: Use baggage overwrite mode, reduce rotation frequency, retain feature-gated buffer/proxy changes, and temporarily use a 60-second ALB timeout.
